# Fiktive Beispielwoche
Dieses Beispiel ist kein aktives Thema und kein Nachweis deines Wissens.
Es zeigt sechs aufbauende Einheiten, sieben Dokumentationen und zwei Review-Runden.
Die Schülerantworten sind zur Demonstration ausgefüllt. Der Freitag enthält eine
ursprüngliche fehlerhafte Antwort und die spätere eigenständige Korrektur; die KI
nennt im Review niemals den richtigen Wert. Die zweite Runde bestätigt die Änderung.
